塔罗斯监狱求解器 {version} 中文版

《火炬之光：无限》第 16 赛季“塔罗斯监狱”玩法的走法提示工具，以浮层形式画在游戏窗口上。
本软件只截取游戏窗口画面、读取游戏写在硬盘上的日志文件；不读写游戏内存、不注入、不替你按键或点击。每一步都由你自己操作。

【使用方法】
1. 把压缩包完整解压到一个单独的文件夹（不要直接在压缩包里运行）。
2. 运行 TartarusSolver.exe，再打开游戏，进入塔罗斯监狱。软件会自动找到游戏窗口和日志。
3. 第一次连接游戏时会询问游戏语言，国服选“简体中文”。
4. 正常游玩：浮层上加粗绿框就是推荐走法，框上方是预计本局结束时的绮彩/至臻秘藏数量；
   如果推荐的是“吃”或“寻猎”，目标牢房会用虚线框标出。

游戏需要用“窗口化”或“无边框窗口”模式，独占全屏无法显示浮层。
{runtime}
【快捷键】（游戏或本软件在前台时有效）
  Ctrl+Shift+S  立即扫描            Ctrl+Shift+R  自动扫描 开/关
  Ctrl+Shift+H  浮层 开/关          Ctrl+Shift+B  保存问题报告（截图、软件日志、本局游戏日志）

【关于中文版】
- 基于 glcoder/TartarusSolver v{version}（MIT 协议）汉化，识别、求解等功能与原版完全相同。
- 界面中的游戏术语取自游戏官方简体中文文本，与游戏内叫法一致。
- “保存问题报告”只保存在本机（%LOCALAPPDATA%\TartarusSolver\reports），不会上传。
- “检查原版更新”只提醒原作者发布了新版本，不会自动安装（原版是英文界面）。
- 软件内部日志仍为英文，便于和原版对照排查。

设置文件：%LOCALAPPDATA%\TartarusSolver\settings.json
原项目：https://github.com/glcoder/TartarusSolver
