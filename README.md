# 塔罗斯监狱求解器 · 中文版

《火炬之光：无限》“塔罗斯监狱”玩法的走法提示工具：读取游戏画面和日志，推演每一步，把**收益最高的一步**用红字和绿框标在游戏画面上。

> **本项目基于 [glcoder/TartarusSolver](https://github.com/glcoder/TartarusSolver)（作者 Artem Gurevich）修改。**
> 画面识别、规则引擎、求解算法等核心功能全部是原作者的成果，本仓库只做了面向国服玩家的中文版改动。
> 原版自带的中文界面翻译感谢 [xingkinglb](https://github.com/xingkinglb)。
> 按 MIT 协议发布，原作者的版权声明保留在 [LICENSE](LICENSE) 中。原版英文说明见 [README.en.md](README.en.md)。

软件只截取游戏窗口画面、读取游戏写在硬盘上的日志文件；**不读写游戏内存、不注入、不替你按键或点击**，每一步都由你自己操作。

## 下载

到 [Releases](https://github.com/womeizui119/tartarus-solver-cn/releases) 下载最新版：

- `TartarusSolver-版本号-zh-full.zip`：**推荐**，自带运行库，解压即用
- `TartarusSolver-版本号-zh.zip`：体积小，需要先装 .NET 9 桌面运行时和 VC++ 运行库

解压到单独文件夹，运行 `塔罗斯监狱求解器.exe`，再打开游戏进入塔罗斯监狱即可。游戏需用“窗口化”或“无边框窗口”模式。

已安装的中文版有新版本时会自动提示，点一下即可更新。

## 中文版改了什么

- 主界面精简：最上面一行红字直接写“该怎么走”，其他设置收进“⚙ 设置”里
- 只显示收益最高的一步，不再列出次选；游戏画面上方加红色大字提示
- 识别间隔从 0.5 秒缩短到 0.1 秒，绿框跟画面更及时
- 默认简体中文，自动识别国服窗口标题和 TapTap 等国服安装位置的游戏日志
- 浮层字号、主窗口透明度可调
- 程序有了自己的图标，exe 和文件夹改为中文名
- 问题报告只保存在本机，不上传
- 自动更新改为从本仓库获取中文版

## 跟进原版

`tools/zh/build_zh.py` 会把中文版改动搬到原版的新版本上、编译并打包（版本号为原版号加一位修订号，如 0.7.44.1）。
